# AI 数字人英语外教（Web 电影级）开发方案 v1

## 1. 已确认目标与约束

### 1.1 目标
- 平台：**Web 优先**。
- 数字人：**电影级真实感**（高保真脸部细节、口型、微表情）。
- 人设：英语外教 + 脱口秀风格，默认 `savage-lite`，可升级为更强喜剧 diss。
- 训练目标：**口语流利度优先**。
- 时长：30/60/120 分钟可选，默认 60 分钟。
- 隐私：允许云端存储与个性化训练（在用户授权前提下）。
- 声音：支持用户音色克隆，且首版采用**完全用户音色**。
- 形象数据源：首版使用**用户照片**建模（建议 >=20 张）。
- 首批场景：**日常闲聊**。

### 1.2 新增关键需求
1. **Diss 要更重但更好笑**：参考 roast/comedy club 风格，攻击观点，不攻击人格，不触发侮辱边界。
2. **主动机制不是只换题**：优先做
   - 苏格拉底式追问（追逻辑、追因果、追证据）
   - 批判式提问（替代立场、反例挑战、条件变化）
3. **中英夹杂可理解**：用户卡壳时允许 “Chinglish + 中文补充” 输入，系统需自动重构成自然英文。

## 2. 产品能力拆解

## 2.1 对话核心（Tutor Brain）
- 多层输出协议（每轮都返回）：
  - `coach_reply`：数字人的主回复（英文，必要时中文提示）
  - `error_map`：语法/用词/逻辑/流利度问题
  - `rewrite`：更自然表达（CEFR 分级）
  - `follow_up`：苏格拉底或批判式下一问
  - `roast_line`：喜剧 diss 文案（可空）
  - `drill`：强制复述或替换练习

## 2.2 语音与多语理解
- ASR：支持中英混说、口音容错、断句不完整输入。
- 语义重构器：
  - 将中文补丁信息融合到英文句意中。
  - 输出三版：直译版、自然口语版、面试正式版。

## 2.3 电影级数字人
- 形象生成：基于用户照片/视频做 identity-preserving 数字人。
- 表情系统：
  - 默认讲解、鼓励、质疑、调侃四大状态。
  - roast 触发时用“夸张但不恶意”的喜剧表情包络。
- 口型同步：phoneme 级别 lip-sync + 眨眼/停顿微动作。

## 2.4 主动学习编排器
- 沉默检测（3~5s）不直接换题，先“沿上文追问”：
  1) 澄清问题（What exactly do you mean by ...?）
  2) 论证问题（Why do you think that is true?）
  3) 反例问题（What if the opposite happens?）
- 连续卡壳两次后，降维给 scaffold（句型模板 + 关键词）。

## 2.5 进度与报告
- 指标：
  - Words per minute（流利）
  - 平均停顿时长（卡顿）
  - 纠错重复命中率（吸收度）
  - 词汇多样性（TTR）
- 每日输出：
  - Top 10 错误
  - 10 条“你常说错但今天修正了”的句子
  - 次日热身脚本（5 分钟）

## 3. 风格与安全边界（重口味 diss 版）

## 3.1 Roast 策略
- 允许：夸张、反讽、节奏梗、call-back。
- 禁止：人格羞辱、外貌歧视、家庭/疾病/民族等敏感攻击。
- 文案公式：
  - 先笑点（roast）→ 再纠错（teach）→ 再鼓励（recover）→ 再复述（drill）。

示例：
- “That sentence had three tenses fighting each other like a reality show. Great drama, terrible grammar. Try this: ...”

## 3.2 强度档位
- `normal`：轻松吐槽。
- `savage-lite`：默认。
- `savage-standup`：更狠更搞笑（你要求的方向），但仍受安全边界约束。

## 3.3 档位切换策略（已确认）
- Diss 强度做成实时可切换（课程中可改）：`normal` / `savage-lite` / `savage-standup`。
- 默认档维持 `savage-lite`，用户可一键切到 `savage-standup`。

## 4. 技术架构（Web First）

## 4.1 前端
- Next.js + WebRTC 音视频流。
- 实时字幕层：原句、纠错句、建议句三轨显示。
- 课堂控件：时长选择（30/60/120）、diss 档位、主题模式。

## 4.2 后端
- Orchestrator（Python/Node 均可）
  - Session 管理
  - Prompt 编排
  - 状态机（沉默/卡壳/追问/复盘）
- 实时推理服务
  - 流式 LLM 输出
  - ASR/TTS 双通道
  - 表情驱动事件流

## 4.3 数据层
- 用户画像：目标、弱项、喜好。
- 错误记忆库：按语法类型 + 场景标签聚合。
- 训练日志：支持周报/月报。

## 5. 预算建议（先给你可落地版）

按 1 名重度用户（2h/天）估算：
- 实时 ASR + TTS + LLM + 数字人推流：约 **¥80 ~ ¥300/天**（取决于模型档位与数字人方案）
- 月成本约 **¥2400 ~ ¥9000**

建议策略：
1. MVP 阶段用“高质量但非最高档数字人”验证留存。
2. 达到 >40% 7日留存后切电影级全开模式。
3. 高频时段启用动态降本（如长静默时降低渲染频率）。

## 6. 分阶段里程碑

## Phase A（2 周）可用 MVP
- Web 端实时对话。
- 中英夹杂识别 + 纠错三联输出。
- 苏格拉底/批判式追问。
- savage-lite roast。

**验收指标**
- 首 token 延迟 < 1.2s（文本）
- 语音响应首包 < 1.8s
- 每 10 分钟至少 6 次有效开口

## Phase B（3~4 周）电影级数字人
- 用户形象定制。
- 高保真表情与口型同步。
- roast 动作模板联动。

## Phase C（2 周）学习飞轮
- 个性化错误记忆。
- 日/周报告。
- 自动复习脚本。
