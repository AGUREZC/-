# 电力方舱项目管理驾驶舱使用说明

这是一个纯前端小程序，用于帮助电化学储能公司研发项目经理管理数据中心电力方舱开发项目。它可以展示项目进展、录入任务、跟踪里程碑和风险，并导出量化任务数据。

## 快速启动

本项目不依赖后端服务，直接用浏览器打开 `index.html` 即可使用。

### 方式一：直接打开

1. 在文件管理器中进入项目目录。
2. 双击 `index.html`。
3. 浏览器打开后即可查看项目驾驶舱。

### 方式二：本地静态服务

如果你希望用本地服务访问，可以在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

## 页面功能说明

### 1. 核心指标区

页面顶部会自动展示：

- 总体完成率：根据所有任务完成率自动平均。
- 任务完成：统计完成率达到 100% 的任务数量。
- 里程碑达成：统计已完成里程碑数量。
- 高风险事项：统计风险台账中的高风险数量。

### 2. 新增 / 量化任务

在左侧表单中填写：

- 任务名称
- 所属模块
- 责任人
- 截止日期
- 完成率
- 优先级

点击“添加任务”后，新任务会立即进入任务看板，并参与总体完成率和模块进展计算。

### 3. 模块进展

系统会按照任务所属模块自动汇总平均完成率，适合用于研发周会查看各专业模块推进情况，例如：

- 总体方案
- 电气一次
- 电气二次
- 热管理
- 消防安全
- 结构集成
- 测试验证
- 供应链

### 4. 任务看板

任务看板展示任务名称、模块、责任人、截止日期、优先级和进度。

点击每行右侧的“+10%”按钮，可以快速把该任务进度增加 10%，最高不超过 100%。

### 5. 关键里程碑

页面下方展示项目关键节点，用于跟踪需求澄清、方案冻结、详细设计评审、样机集成与测试等阶段性成果。

当前版本的里程碑数据写在 `src/app.js` 中，如需调整默认里程碑，可以修改 `milestones` 数组。

### 6. 风险台账

风险台账用于记录影响项目目标的关键问题，并给出建议动作。当前版本的风险数据写在 `src/app.js` 中，如需调整默认风险，可以修改 `risks` 数组。

### 7. 导出量化数据

点击页面右上角“导出量化数据 CSV”，浏览器会下载 `电力方舱项目量化数据.csv`。

导出的字段包括：

- 任务名称
- 模块
- 责任人
- 截止日期
- 优先级
- 完成率

该文件可以用 Excel、WPS 或项目周报模板打开，用于量化汇报。

## 当前版本限制

- 数据只保存在当前浏览器页面内，刷新页面后新增任务会丢失。
- 暂无账号权限、多人协同和后端数据库。
- 如果要在公司内部长期使用，建议后续增加本地存储、数据库、登录权限和周报模板导出。
